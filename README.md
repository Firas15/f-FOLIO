# Портфолио Фираса Хашаба

Сайт — статичный HTML + CSS + JS без сборки. Админка — PHP без базы данных.

## Структура

```
index.html               разметка сайта
assets/css/style.css     стили, темы, анимации
assets/js/main.js        логика сайта: ноутбук, курсор, окно проекта, терминал
data/portfolio.js        ВЕСЬ контент (его правит админка)
assets/img/              картинки; assets/img/uploads/ — загруженные через админку
admin/                   админка
  index.php              интерфейс
  api.php, lib.php       сервер: вход, сохранение, загрузка фото, резервные копии
  set-password.php       задать/сбросить пароль из консоли
  storage/               пароль (в виде хеша), попытки входа, резервные копии
```

## Запуск на компьютере

Нужен PHP 8.1+. В папке сайта:

```
php -d extension_dir=C:\php\ext -d extension=gd -d extension=fileinfo -d extension=mbstring -d upload_max_filesize=16M -d post_max_size=20M -S 127.0.0.1:8080
```

Сайт откроется на http://127.0.0.1:8080, админка — на http://127.0.0.1:8080/admin/.
Флаги `-d` включают обработку картинок: в вашем PHP нет php.ini, поэтому расширения подключаются при запуске.

## Пароль

- **Первый вход.** Откройте `/admin/` на своём компьютере и придумайте пароль. С чужого адреса первый пароль задать нельзя, поэтому на хостинге никто не опередит вас.
- **Сменить пароль** — «Настройки → Пароль».
- **Забыли пароль** — `php admin/set-password.php`, либо удалите `admin/storage/auth.php` и задайте пароль заново локально.
- После 5 неверных попыток вход с этого IP блокируется на 10 минут.

## Выкладка на хостинг (Timeweb, Beget и т. п.)

1. Задайте пароль локально, затем загрузите **всю** папку сайта вместе с `admin/storage/auth.php`.
2. Дайте PHP права на запись в папки `data/`, `assets/img/uploads/`, `admin/storage/` (обычно 755 или 775).
3. В панели хостинга выберите PHP 8.1 или новее. Если большие фото не загружаются, поднимите `upload_max_filesize` и `post_max_size` до 16–20 МБ.
4. Файлы `.htaccess` закрывают служебные папки на Apache. Если хостинг на чистом nginx, запретите доступ к `/admin/storage/` в его настройках. Пароль там всё равно хранится только в виде хеша внутри PHP-файла.

## Что умеет админка

- **Работы:** добавление, редактирование, удаление. Порядок меняется перетаскиванием или стрелками. ★ выводит работу на ноутбук (первые три отмеченные). Есть кнопка «скрыть»: работа-черновик сохраняется, но не видна на сайте.
- **Фото работы:** можно загрузить несколько файлов (кнопкой или перетаскиванием с компьютера), менять их порядок перетаскиванием и назначать обложку. На сервере фото автоматически переводятся в WebP и уменьшаются до ширины 1920 px.
- **Достижения:** всё то же самое, плюс тип (диплом, сертификат, конференция, шоукейс).
- **Профиль:** имя, тексты, фото на первом экране, учёба, работа, бегущая строка.
- **Контакты:** Telegram, почта, GitHub, ВК, любые ссылки. Ссылка собирается сама из ника или адреса.
- **Настройки:** смена пароля, резервные копии с откатом (хранятся 40 последних), удаление неиспользуемых фото, экспорт в JSON.
- **Сохранение:** кнопка «Сохранить» или Ctrl+S. Если данные поменяли в другой вкладке, админка спросит, перезаписывать ли их.

## Ручная правка

`data/portfolio.js` можно править руками. Главное — чтобы после `window.PORTFOLIO =` оставался чистый JSON: без комментариев, с ключами в кавычках. Иначе админка покажет ошибку, и файл надо будет поправить или откатить из резервной копии.

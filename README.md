# F/FOLIO

Сайт — статичный HTML + CSS + JS без сборки. Админка — PHP без базы данных.

## Структура

```
index.html               разметка сайта
assets/css/style.css     стили, темы, анимации
assets/js/main.js        логика сайта: ноутбук, курсор, окно проекта, терминал
data/portfolio.js        ВЕСЬ контент (его правит админка)
assets/img/              картинки; assets/img/uploads/ — загруженные через админку
admin/                   админка
  index.php              интерфейс
  api.php, lib.php       сервер: вход, сохранение, загрузка фото, резервные копии
  set-password.php       задать/сбросить пароль из консоли
  storage/               пароль (в виде хеша), попытки входа, резервные копии
```

## Запуск на компьютере

Нужен PHP 8.1+. В папке сайта:

```
php -d extension_dir=C:\php\ext -d extension=gd -d extension=fileinfo -d extension=mbstring -d upload_max_filesize=16M -d post_max_size=20M -S 127.0.0.1:8080
```

Сайт откроется на http://127.0.0.1:8080, админка — на http://127.0.0.1:8080/admin/.
Флаги `-d` включают обработку картинок: в вашем PHP нет php.ini, поэтому расширения подключаются при запуске.

## Пароль

- **Первый вход.** Откройте `/admin/` на своём компьютере и придумайте пароль. С чужого адреса первый пароль задать нельзя, поэтому на хостинге никто не опередит вас.
- **Сменить пароль** — «Настройки → Пароль».
- **Забыли пароль** — `php admin/set-password.php`, либо удалите `admin/storage/auth.php` и задайте пароль заново локально.
- После 5 неверных попыток вход с этого IP блокируется на 10 минут.

## Бесплатно на GitHub Pages

Сайт открывается по адресу https://firas15.github.io/f-FOLIO/.

- GitHub Pages умеет только статические файлы, поэтому PHP-админка там не работает. `_config.yml` её не публикует.
- Контент правьте так: запустите сайт локально (см. «Запуск на компьютере»), отредактируйте всё в `/admin/`, затем отправьте изменения в GitHub (Commit → Sync). Через минуту обновится и сайт.
- Загруженные фото лежат в `assets/img/uploads/` — их тоже нужно отправлять в GitHub. Пароль и резервные копии (`admin/storage/`) в GitHub не попадают.

## Выкладка на хостинг с PHP (Timeweb, Beget и т. п.)

1. Задайте пароль локально, затем загрузите **всю** папку сайта вместе с `admin/storage/auth.php`.
2. Дайте PHP права на запись в папки `data/`, `assets/img/uploads/`, `admin/storage/` (обычно 755 или 775).
3. В панели хостинга выберите PHP 8.1 или новее. Если большие фото не загружаются, поднимите `upload_max_filesize` и `post_max_size` до 16–20 МБ.
4. Файлы `.htaccess` закрывают служебные папки на Apache. Если хостинг на чистом nginx, запретите доступ к `/admin/storage/` в его настройках. Пароль там всё равно хранится только в виде хеша внутри PHP-файла.

## Что умеет админка

- **Работы:** добавление, редактирование, удаление. Порядок меняется перетаскиванием или стрелками. ★ выводит работу на ноутбук (первые три отмеченные). Есть кнопка «скрыть»: работа-черновик сохраняется, но не видна на сайте. Статус «Уже работает» / «В разработке» задаёт фильтр в разделе «Проекты»; карточки «Скоро здесь» попадают в «В разработке».
- **Вид работы:** сайт, приложение, бот, база данных или модуль. От вида зависит заголовок карточки (окно браузера, окно программы, чат, клиент БД, терминал); если фото нет, на сайте рисуется автоматическая обложка под вид. Подпись кнопки подбирается по ссылке: GitHub — «Код на GitHub», Telegram — «Открыть бота», сайт — «Открыть сайт».
- **Фото работы:** можно загрузить несколько файлов (кнопкой или перетаскиванием с компьютера), менять их порядок перетаскиванием и назначать обложку. На сервере фото автоматически переводятся в WebP и уменьшаются до ширины 1920 px.
- **Достижения:** всё то же самое, плюс тип. Типы (вкладки на сайте) правятся там же: название вкладки и подпись на карточке, порядок, добавление, удаление пустых. Тип без видимых достижений на сайте не показывается.
- **Профиль:** имя, тексты, фото на первом экране, учёба, работа, бегущая строка.
- **Первый экран (в «Профиле»):** до 4 цифр под именем — «авто» (число работ, работающих сайтов, достижений; подпись подбирается сама) или свой текст вроде «5+ лет в коде». Рядом три монитора с превью топ-3 работ (отмеченных ★), их можно выключить.
- **Контакты:** Telegram, почта, GitHub, ВК, любые ссылки. Ссылка собирается сама из ника или адреса.
- **Настройки:** смена пароля, резервные копии с откатом (хранятся 40 последних), удаление неиспользуемых фото, экспорт в JSON.
- **Предпросмотр:** кнопка в верхней панели и в редакторе работы/достижения открывает сайт с несохранёнными правками (из редактора — сразу с открытым окном этой записи, даже скрытой). Пока вкладка открыта, она обновляется сама после каждой правки.
- **Сохранение:** кнопка «Сохранить» или Ctrl+S. Если данные поменяли в другой вкладке, админка спросит, перезаписывать ли их.

## Ручная правка

`data/portfolio.js` можно править руками. Главное — чтобы после `window.PORTFOLIO =` оставался чистый JSON: без комментариев, с ключами в кавычках. Иначе админка покажет ошибку, и файл надо будет поправить или откатить из резервной копии.

## Английская версия

Кнопка EN / RU в шапке, `?lang=en` в адресе или `lang en` в терминале (выбор запоминается).

- Текст страницы — в `index.html`: русский в разметке, английский в атрибутах `data-en`, `data-en-html`, `data-en-aria`, `data-en-title`, `data-en-alt`, `data-en-cursor`. Подписи из скрипта — `tr("рус", "eng")` в `assets/js/main.js`.
- Содержимое (профиль, работы, достижения, типы, цифры, подписи контактов) — поле `en` у каждой записи в `data/portfolio.js`. Админка английских полей не показывает, но при сохранении их не стирает. Пустое или отсутствующее поле — на сайте остаётся русский текст.
- Если в админке поменять русский текст или добавить новую запись, английскую версию нужно дописать в `data/portfolio.js` руками (тот же JSON, ключ `en` с теми же полями: `title`, `category`, `tags`, `short`, `description` у работ; `title`, `org`, `date` у достижений).

## Пасхалка

Клавиша <kbd>`</kbd> (или <kbd>ё</kbd>) открывает терминал на сайте. Попробуйте `help` и `sudo hire firas`.

## Вступление

По умолчанию — «код → сайт»: редактор печатает разметку, проходит сборка, и строки превращаются в первый экран. Запасной вариант — VHS-телевизор.

- Переключить: `?intro=vhs` или `?intro=code` в адресе (выбор запоминается), либо в терминале `intro vhs` / `intro code`.
- Вариант по умолчанию для всех задаётся константой `INTRO_DEFAULT` в `assets/js/main.js`.
- Полное вступление показывается один раз за визит, при обновлении страницы — короткое. Клик или клавиша пропускают его.
